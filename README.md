A program that writes one funny line to `/output/entry.txt`: a bank
account with two-factor authentication that texts "no" twice before
every purchase. Entered in make.fun's "One-Line Laugh-Off" bounty.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt` (92
characters, one line, no trailing newline). Running it again writes
the exact same bytes.
